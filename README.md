# My Money

A simple personal money tracker that runs in your phone browser.

## Features
- Record income and spending, with accounts (Cash, Bank, Wallet)
- Monthly budget and category budgets
- Investment tracking with gain or loss
- Monthly review with a score and feedback
- Write notes: a daily notes section
- Optional PIN lock

## How to use
Open the page link on your phone, then use "Add to Home Screen".

## Your data
All entries are saved only in your own browser on your own device.
Use Settings > Show and copy backup to keep a safe copy.

## Built with
Plain HTML, CSS and JavaScript in one file (index.html). No server needed.
